# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not report a vulnerability in a public issue. Report it privately through GitHub instead: on the [Security tab](https://github.com/FunFR/ha-evlink-home/security) of this repository, select **Report a vulnerability**. Only you and the maintainer can see the report.

Include the integration version, the Home Assistant version, and the steps to reproduce. Do not include your own password, access tokens, email address or serial numbers.

This integration is maintained in spare time, so fixes are made on a best-effort basis.

Vulnerabilities in the Wallbox itself, the Wiser Home app or the Wiser Home cloud are outside this project: please report them to Schneider Electric.
